# M0-3 代码排查报告

## 运行方式

```bash
# 默认读取当前目录的 sensor_data.csv，写入 cleaned_data.csv
python3 sensor_analyzer.py

# 显式指定输入、输出
python3 sensor_analyzer.py --input sensor_data.csv --output cleaned_data.csv
```

程序使用总体标准差：

\[
\mu = \frac{1}{N}\sum_i x_i,\qquad
\sigma = \sqrt{\frac{1}{N}\sum_i (x_i-\mu)^2}
\]

保留满足 `abs(value - mean) <= 2 * std` 的数据。样例计算结果为：

```text
共读取 60 条数据
均值 mean = 50.431537
标准差 std = 18.503279
清洗后剩余 57 条
```

剔除的 3 条离群值为 `(5.8, 118.4)`、`(5.9, 132.7)`、`(6.0, -21.3)`。

## 缺陷清单

以下行号均指修复前的原脚本。

| 序号 | 原位置 | 现象 | 原因 | 修复 |
| --- | --- | --- | --- | --- |
| 1 | 第 37 行，`row["Value"]` | 首次运行立即出现 `KeyError: 'Value'` | CSV 表头是小写 `value`，字典键区分大小写 | 改为 `row["value"]` |
| 2 | 第 61 行，`output_path = os.path.join("/", ...)` | 修好列名后出现 `FileNotFoundError: '/out/cleaned_data.csv'` | 多加了根目录 `/`，同时写死输出目录，目标目录还不存在 | 默认使用当前工作目录下的相对路径 `cleaned_data.csv`，并支持 `--output` |
| 3 | 第 52-53 行，`acc += (v - mean)`、`acc / len(data)` | 标准差显示为 `-0.0000`，离群值判断失效 | 只累加有符号偏差，没有平方，也没有开方；正负偏差还会相互抵消 | 改为累加平方偏差，再除以 `N` 并调用 `math.sqrt` |
| 4 | 第 57 行，`v > mean + 2 * std` | 只能发现偏大的值，偏小的值会残留 | 仅判断上界，没有按 `abs(value - mean) > 2 * std` 做双侧判断 | 增加绝对值判断，同时覆盖上下两侧 |
| 5 | 第 56-58 行，遍历 `data` 时调用 `remove` | 连续离群值会漏删，样例中 `132.7` 残留 | 删除元素后列表缩短，后续元素前移，而迭代器仍继续访问下一个下标 | 先遍历原列表记录保留下标，再统一构造新列表 |
| 6 | 第 28、65 行，`cleaned` | 清洗后剩余数始终为 0，输出只有表头 | `cleaned` 只初始化，从未写入任何结果 | 在按索引筛选后同步筛选 `times` 和 `data`，再组成 `(time, value)` 列表 |
| 7 | 第 65-66 行，`writer.writerow([v])` | 即使补入结果，CSV 也会丢失 `time`，列数与表头不一致 | 清洗结果应按两个字段输出，原代码只写了数值，且保存的是尚未填充的列表 | 遍历 `(t, v)` 并写入 `[t, v]` |
| 8 | 第 22-33、62 行，固定文件名和裸 `open` | 缺文件、空文件、列名错误或非数值内容都会产生 `Traceback`；也不能指定输入输出 | 没有命令行参数、表头和数值校验，也没有统一捕获可预期错误；文件未使用上下文管理器 | 使用 `argparse`、`with open`、有限数值和列名校验，统一输出错误并以非 0 状态退出 |

## 修复顺序和依赖

1. 先修正列名，否则程序尚未进入统计逻辑。
2. 修正输出路径，否则无法验证清洗结果。
3. 修正标准差公式，否则阈值本身错误。
4. 改为双侧离群值判断。
5. 消除遍历时删除造成的漏检。
6. 正确保存与数值对应的 `time,value`。
7. 按两列写入 CSV。
8. 增加命令行接口和异常输入处理。

前几个问题会互相掩盖。例如标准差恒为 0 时，离群值判断基本失效；`cleaned` 始终为空时，错误的两列写入逻辑也不会暴露。

# 22SmartCar —— 智能车竞赛考核记录

本仓库用于记录智能车竞赛各模块的完成过程、代码与踩坑记录。

## 仓库结构

```
M0/           环境搭建（分 M0-1 ~ M0-4 四个子任务）
M1 ~ M6/      后续模块，边做边补
日志/         日常记录
```

每个模块目录内应包含：

- `README.md` —— 该模块的说明与过程记录
- 相关代码
- 截图 / 输出等佐证材料

## 开发环境

| 项目 | 内容 |
|---|---|
| 操作系统 | Ubuntu 22.04.5 LTS（物理机，安装在外置硬盘） |
| ROS 2 | Humble（`/opt/ros/humble`） |
| Python | 3.10.12（系统）+ Miniconda3 |
| 编译器 | gcc / g++ / make / cmake |
| 编辑器 | VS Code 1.140.0 |
| 版本控制 | git（本仓库） |
